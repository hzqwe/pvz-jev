## 行为变化

- ID 0 生成当前版本独立档案，产阳光与射击同时参与经济摘要；其他版本退出时恢复原档案。
- 火力共用命中几何：前向射手不算身后敌人的支援，短射程不算远处火力；雷果子只计可命中同行目标，追踪伤害分摊而不按敌人数复制。
- 女王过火偏好要求同行、醒着且位于射手与目标之间；保留保守伤害，不用未知倍数承诺救场。
- 安全富阳光场景的补阵型在候选与最终决策侧一致，普通远处僵尸不再让补阵型规则失效；危险和储蓄保留资源仍有效。
- 空场已有前向射手保留建阵参考，避免把整齐阵型误认成零火力；有敌人时仍检查真实命中条件。
- 审计与运行时共用只读档案解析，分别显示 mechanics_available / mechanics_bound、inferred_fields / unverified_fields；不会改绑定、成本或 TTL。

API 调用次数未变。按照 [TypeSafe 结构化 state 文档](https://docs.typesafe.ai/concepts/state)，
只给当前卡组与局面的能力摘要，补了紧凑经济估计和候选组合理由；不把整个百科发给 Jev。
摘要略增长度，实际 token 数与费用未进行付费测量，不能承诺完全不变。
